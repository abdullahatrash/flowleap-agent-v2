name: flowleap-invalidity-analysis
description: Hunt prior art against a granted patent's claims and build an invalidity chart
---
Build an invalidity case against the granted patent I name below. Pin its priority date, decompose the independent claims into elements, and search patents and scholarly literature published before that date for art that reads on each element. Tag every reference as novelty-destroying on its own, useful only in combination, or background only, and support each mapping with a verifiable quotation and a clickable source citation. Flag which references the examiner never saw, and state clearly every element for which you found no art. Save an invalidity chart as outputs/invalidity-chart.md in the workspace and give me a brief summary with a link to it.
