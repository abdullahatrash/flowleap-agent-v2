# UPC Rules of Procedure — Reference

**Compiled:** 2026-07-10. Derived from a study of the Unified Patent Court case-management system's rule configuration plus the UPC Rules of Procedure. **Caveat:** the current UPC Rules of Procedure and the court's orders govern; treat this as a plain-language aid, not authority. Windows below are the ranges the rules contemplate, described for orientation only — they are NOT party-specific deadlines. A real deadline depends on the service date, extensions, and case-management orders and must be confirmed with counsel and the court.

## Case lifecycle (six-phase model)

Written procedure → interim procedure (including the RoP 264 interim conference) → oral procedure → deliberation → decision. Provisional-measures and appeal tracks run alongside this backbone.

## Rules by function

| RoP | Function | Typical window (describe, do not compute) |
|-----|----------|-------------------------------------------|
| 5 | Opt-out (and its withdrawal) from UPC jurisdiction | Available through the transitional period; effective on entry in the register |
| 80 | Case management / cost management | As set by the judge-rapporteur's orders |
| 126 | Revocation action (standalone) | Defence due within the period set after service; written phase then proceeds |
| 150 / 151 | Determination of damages (separate proceeding after a finding of infringement) | Application follows the merits decision; its own written exchange |
| 192 | Order to preserve evidence and to inspect (application) | Can be sought urgently, before or with the main action |
| 199 | Measures to preserve evidence (saisie-style) | Ordered on an expedited basis; execution windows set in the order |
| 200 | Order for inspection of premises | Expedited, alongside RoP 192/199 |
| 206 | Provisional measures ordered without hearing the defendant (ex parte) | Granted in urgent cases; defendant may seek review afterwards |
| 221–228 | Appeals cluster (leave, statement of appeal, response) | Appeal lodged within the set period of the decision/order; response follows |
| 223 | (within appeals) statement of grounds / response mechanics | Set periods running from the appeal steps |
| 234 | Application for suspensive effect of an appeal | Filed with or after the appeal; decided by the Court of Appeal |
| 245 | Stay of proceedings | On application or the court's motion; duration set by order |
| 264 | Interim conference | Held in the interim phase to prepare the oral hearing |
| 320 | Application for rehearing (exceptional review after a final decision) | Strict outer limits; extraordinary remedy only |
| 333 | Review of case-management orders by the panel | Requested within a short period of the order |
| 354.4 | Enforcement / penalty-payment mechanics for orders | Set in the enforcing order |
| 356 | General provisions on periods and their extension | Governs how periods are counted and may be extended |

## The boundary this reference exists to hold

Every window above is a range the rule contemplates, for explaining what a step involves. It is not a deadline calculation. When a user wants their actual date, describe the window and route them to counsel and the court for the binding figure.
