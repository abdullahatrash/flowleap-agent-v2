# EPO section order (Rule 42 EPC)

Write the description in the order of Rule 42(1) EPC. Rule 42(2) allows a
different order only where it makes the invention easier to understand;
keep this order unless the attorney asks otherwise.

| # | Heading | Rule | Content and source |
|---|---------|------|--------------------|
| 1 | Title | Rule 41(2)(b) | The title as in the request, short and technical. |
| 2 | Technical field | Rule 42(1)(a) | The field the invention relates to, usually in the words of the claim 1 preamble. |
| 3 | Background art | Rule 42(1)(b) | The art the disclosure and the prior-art search name, with the documents cited by number. Describe what each document teaches; this is where the closest prior art (D1 of the claim-drafting step) goes. |
| 4 | Summary of the invention: technical problem and solution | Rule 42(1)(c) | The objective technical problem in relation to the closest background art, then the invention as claimed as its solution, then the advantageous effects. Effects come from the disclosure; an effect the disclosure does not state is an Inventor Question. |
| 5 | Brief description of the drawings | Rule 42(1)(d) | One sentence per figure from `figures.md`. |
| 6 | Detailed description of embodiments | Rule 42(1)(e) | At least one way of carrying out the invention as claimed, with examples where they exist, using the numerals of `figures.md`. Working examples in past tense only when the inventor ran them. |
| 7 | Industrial application | Rule 42(1)(f) | Only when it is not obvious from the description; source `template` or `instruction`. |
| 8 | Claims | Rule 43 | The Approved Claims, unchanged: two-part form where appropriate, one independent claim per category (Rule 43(2)), each claim one sentence, no "as shown in Fig. 1" (Rule 43(6)), reference signs in parentheses (Rule 43(7)). Heading contains "Claims". |
| 9 | Abstract | Rule 47 | Preferably at most 150 words, with the reference signs of the main features in parentheses, and the figure to publish with it named, e.g. "(Fig. 1)" (Rule 47(4)). Heading contains "Abstract". |

## EPO practice notes

- **Added matter (Art. 123(2) EPC).** After filing, nothing can be added that
  is not directly and unambiguously derivable from the application as filed.
  Every feature the claims may later need must be in this description now,
  from a source; a feature filled in by the model cannot be removed safely
  later. That is why a gap is an Inventor Question.
- The technical problem is stated, unlike the US template, which states no
  objects of the invention (see [us-section-order.md](us-section-order.md)).
- Claims must be supported by the description (Art. 84 EPC): keep the
  claim terms literally in the description.
