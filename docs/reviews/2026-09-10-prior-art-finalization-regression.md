# Prior-art finalization regression boundary

The observed rehearsal exposed an orchestration gap: the evidence writer was available and explicitly instructed, but a generic file creation saved the report. Validation of an optional template did not cover task completion. Successful local evidence lookup also did not establish correct interpretation of claims or quantities.

This change adds a bounded completion check to the common agent tool loop. For explicit English prior-art deliverable requests followed by patent retrieval, generic writes remain working drafts until the structured writer produces a receipt binding the report and execution companion to their exact bytes. The request and results survive ordinary conversation continuations, including scope replies and request-limit checkpoints. A new report request starts a new contract. A changed or missing report/companion loses validation; unrelated notes remain editable. The loop permits two recovery attempts, then displays an explicit unvalidated-draft status. If the writer is unavailable, that status is immediate.

The recognizer covers explicit English prior-art report/review/save/write/output requests; it is not a universal intent classifier. Quoted output paths support spaces and Unicode; explicit Markdown targets following save/write/update/revise are checked. Ambiguous or implicit paths are not guessed. Single-document questions and local evidence inspection do not create new research obligations. This is an agent-workflow correctness check, not an adversarial filesystem security boundary. Model text can already have streamed before the finalization check; the final validation notice is authoritative. Cancellation and hard request limits retain their existing behavior.

Stored evidence lookup now pages the index, preserves complete long lines through character continuations, and labels local work accurately. Repeated source anchors use the same latest recorded source in lookup, validation, and rendering. Supported/partial feature rows must cite claim or description evidence; bibliography links cannot substitute for exact passages. The report labels its complete retrieval inventory as documents with unestablished eligibility, including possible post-cutoff background material.

Exact quotations and complete claim text preserve dependency words, qualifiers, and every original quantity constituent. Model instructions explicitly require review of parent claims, original quantity denominators, averages versus distributions, and uncertainty. These checks do **not** establish semantic entailment, correct arithmetic, complete invention decomposition, eligibility, novelty, or exhaustive research. The separate source-review fields remain model judgments. Live acceptance should still check dependent-scope interpretation, all constituents in percentage conversions, and final-summary consistency.

Deterministic regressions cover the production completion loop, missing/failed/free-form writers, bounded recovery and unavailable-writer status, report and evidence modification/deletion, continuation state, new report tasks, exact paths, local lookup paging and long Unicode lines, repeated anchors, and search → details → local evidence → report → receipt across synthetic sensor, composition, and battery sources. Existing frozen publication fixtures continue to cover real returned claim structure. These tests do not replace the owner-reviewed post-merge live retest or verify native reader click navigation.

Review follow-up regressions also cover a prose-only checkpoint continuation with no new tool calls, a completed report followed by an unrelated single-patent question, and new retrieval followed by a different report save. Freshness uses the same parsed successful structured-writer receipt selected for the requested target; malformed/free-form receipt-like output cannot advance that boundary.

Validation after review fixes: 100 focused tests in seven suites, plus four evaluation-fixture tests in two suites, passed. The prompt drift checker passed. Evaluation saving/deliverable prose was synchronized in both prompt variants. Regenerating the tool definitions also reconciled pre-existing generated schema drift for `search_patents` and `read_pdf`; their runtime implementations are unchanged. The committed fixture must equal the existing extractor output, as enforced by its integrity test.
